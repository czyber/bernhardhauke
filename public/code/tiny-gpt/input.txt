Hello, world! Here is a small collection of characters for a tiny language model.
The model reads a window of text and tries to predict the character that follows.
An embedding gives each character a vector. A position gives that vector a place.
Attention lets a position gather information from the positions that came before.
A feed-forward network transforms each position, and a residual path carries it on.
At the end, a linear layer assigns a score to every character in the vocabulary.
Scores become probabilities. One sampled character becomes the start of another step.
Hello, reader! This is demonstration data, much too small to train a useful model.
There is no training loop in this project. The weights are still randomly initialized.
To learn, the model would need repeated batches, a backward pass, and an optimizer.
Keep the entire file in view. Follow the shapes, from characters to vectors to scores.
The mechanism is here, even though the knowledge has not been learned yet.
